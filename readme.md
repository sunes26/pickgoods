[프로젝트 기획서] PickGoods: 지마켓 기반 상황 맞춤형 쇼핑 큐레이션

1. 프로젝트 개요

프로젝트 명: PickGoods (픽굿즈)

목표: 사용자의 특정 상황이나 고민에 대해 '지마켓' 위탁판매 중인 979개 상품 중 최적의 아이템을 제안. AI 기반 맞춤형 추천으로 구매 전환율을 획기적으로 향상시킴.

핵심 컨셉: "당신의 상황에 딱 맞는 물건을 지마켓에서 픽(Pick)해드립니다."

현재 보유 상품: 979개 (식품 322개, 컴퓨터 238개, 건강의료용품 117개, 의류 84개, 패션잡화 74개 등)

2. 핵심 타겟 및 소구 포인트

타겟: 합리적인 소비를 지향하며, 지마켓의 멤버십(스마일클럽 등) 혜택을 선호하는 2040 쇼퍼.

문제점:
- 위탁판매 상품 979개가 단순 나열로만 노출되어 낮은 구매 전환율
- 고객이 자신의 상황에 맞는 상품을 직접 찾기 어려움
- 상품의 구매 명분이 약해 구매 결정이 늦어짐

해결책:
- AI가 고객 상황을 분석하여 979개 중 최적의 3개 상품만 추천
- "왜 이 상품이 필요한지" 설득력 있는 스토리텔링 제공
- 단순 가격 경쟁이 아닌 가치 기반 구매 유도로 마진 보호

3. 서비스 프로세스 (User Flow)

메인 페이지: "지금 어떤 상황인가요?" 검색창 및 상황별 퀵 버튼 노출.

입력 단계: * 상황 설정: (예: "집들이 선물을 찾아요", "혼자 캠핑 가는데 필수품이 뭘까요?", "사무실 책상이 너무 좁아요")

우선 순위: 가성비, 디자인, 빠른 배송 등 선택.

예산 범위: 1~20만 원 사이 설정.

AI 분석: image_scraper.py로 수집된 지마켓 상품 썸네일과 데이터를 기반으로 매칭 수행.

결과 페이지: * 추천 리포트: AI가 작성한 "이 물건이 당신에게 필요한 이유" 설명.

이미지 확인: 지마켓에서 직접 추출한 생생한 썸네일 노출.

CTA 버튼: [지마켓에서 상세 보기 / 구매하기]

4. 기술 구현 및 운영 계획

A. 데이터 수집 (Data Pipeline)

플랫폼: 지마켓 (Gmarket)

수집 도구: Selenium 기반 image_scraper.py (지마켓 전용 로직 적용).

관리 방식: goods-list-result.xlsx로 관리되는 884개의 지마켓 위탁판매 상품에서 썸네일 URL을 주기적으로 추출하여 JSON 데이터 구축.

B. AI 로직 (GPT API)

모델: gpt-4o-mini 활용.

추천 전략: 사용자의 상황 키워드와 상품의 태그를 매칭. 지마켓 특유의 할인 시즌이나 상품명 키워드를 분석하여 추천 정확도 향상.

C. 프론트엔드

Stack: Next.js + Tailwind CSS.

특징: 모바일 지마켓 앱으로의 매끄러운 연결(Deep Link) 고려.

5. 마케팅 및 예산 활용 계획 (월 30만 원)

콘텐츠 제작 (5만 원): "지마켓 꿀템 추천", "상황별 PickGoods 활용법" 숏폼 제작.

SNS 유료 광고 (20만 원): 지마켓 이용 비중이 높은 연령대를 타겟으로 인스타그램 광고 집행.

운영 및 API 비용 (5만 원): GPT API 호출 및 도메인 유지비.

6. 기대 효과 및 수익 모델

안정적인 데이터 확보: 크롤링이 용이한 지마켓을 활용하여 끊김 없는 서비스 제공 가능.

빠른 자금 회전: 지마켓의 빠른 정산 주기를 활용하여 위탁판매 운영 자금 확보 용이.

수익 구조 최적화:
- 위탁판매 상품이므로 판매 시 즉시 수익 발생
- PickGoods의 전문적인 추천을 통해 최저가 경쟁이 아닌 '가치 기반 구매' 유도
- AI 추천으로 재고 회전율 향상 및 묻혀있던 상품 판매 기회 증가
- 약 9%의 지마켓 수수료를 감안한 마진 설정으로 수익률 보전

7. 향후 확장 계획

멀티 플랫폼 지원: 지마켓 성공 사례를 바탕으로 옥션 등 타 오픈마켓으로 확장.

지마켓 API 연동: 실시간 가격 및 품절 여부 확인 기능 추가.
